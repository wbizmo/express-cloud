# Express Cloud v1.0.1

Express Cloud v1.0.1 is the finalized production release of the Express Cloud ERP platform.

## Release highlights

- Company, branch, staff, role, permission, session, and audit management
- Product catalogue, categories, brands, suppliers, pricing, and spreadsheet imports
- Branch inventory, stock transfers, adjustments, zero-stock, and low-stock controls
- Procurement, purchase orders, goods receipts, supplier bills, payments, and returns
- Customers, CRM, quotations, invoices, POS sales, credit sales, and partial payments
- Customer receivables, reusable vouchers, sales returns, and payment history
- Standalone receipts, fixed assets, purchase returns, document branding, PDFs, and exports
- Double-entry accounting, chart of accounts, accounting periods, journals, general ledger, trial balance, COGS, and depreciation
- API tokens, versioned API endpoints, backups, recovery tooling, health checks, and operations reporting

## Package contents

The production package includes:

- Application source
- Composer `vendor/` directory
- Compiled frontend assets
- `artisan`
- Production `.env`
- `.env.example`
- `express-cloud-install.sql`
- `FIRST_LOGIN.txt`
- Installation and operational documentation
- SHA-256 package manifest

## Installation

1. Extract the production ZIP.
2. Create an empty MySQL database.
3. Import `express-cloud-install.sql`.
4. Update the database credentials and `APP_URL` inside `.env`.
5. Point the domain document root to the `public/` directory.
6. Ensure `storage/` and `bootstrap/cache/` are writable.
7. Sign in using the credentials in `FIRST_LOGIN.txt`.
8. Rotate the administrator access key immediately.
9. Delete `FIRST_LOGIN.txt` from the deployed server.

The packaged SQL and `.env` must remain together because the seeded administrator account depends on the packaged encryption and blind-index keys.
