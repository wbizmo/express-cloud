# Phase 7 — Enterprise POS and cash control

- Dedicated POS workstation and terminal registry.
- Cashier shift opening, opening float, pay-in/pay-out/refund movements, held carts and deterministic resume.
- Admin-configured payment methods are the only visible tenders.
- Shift close reconciles expected and counted values per tender.
- Material variance and receipt reprints require independent approval.
- Receipt formats support 58mm, 80mm and A4. A receipt is logged only against a confirmed server sale.
