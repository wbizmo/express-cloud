# Express Cloud v1.0.1

Express Cloud v1.0.1 is the finalized production package of the completed
Express Cloud ERP platform.

## Release corrections

- rebuilt the production ZIP with the SQL installer included;
- included the matching production `.env`;
- included first-login administrator credentials;
- included Composer dependencies through `vendor/`;
- included compiled frontend assets;
- removed obsolete sprint, repair, and release-builder shell scripts;
- included installation, accounting, backup, API, recovery, and operations documentation;
- included a SHA-256 package manifest.

## Installation

1. Extract the ZIP.
2. Create an empty MySQL database.
3. Import `express-cloud-install.sql`.
4. Update the database credentials and application URL inside `.env`.
5. Point the domain document root to `public/`.
6. Ensure `storage/` and `bootstrap/cache/` are writable.
7. Sign in using `FIRST_LOGIN.txt`.
8. Rotate the administrator access key immediately.
9. Delete `FIRST_LOGIN.txt` from the deployed server.

The packaged SQL and `.env` belong together because the seeded administrator
record uses the encryption and blind-index keys contained in `.env`.
