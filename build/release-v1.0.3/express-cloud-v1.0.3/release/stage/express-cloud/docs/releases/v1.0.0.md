# Express Cloud v1.0.0

Express Cloud v1.0.0 is the first production release of the completed ERP,
inventory, procurement, CRM, sales, POS, operational finance, accounting,
reporting, API, backup, security, and administration platform.

## Included

- staff access-key authentication;
- companies, branches, roles, permissions, sessions, and audit history;
- products, categories, brands, suppliers, pricing, and Excel imports;
- branch inventory, stock movement history, transfers, adjustments, and alerts;
- procurement, purchase orders, receipts, supplier bills, and returns;
- customers, quotations, invoices, POS sales, partial payments, and credit sales;
- receivables, reusable vouchers, sale returns, and direct purchase recording;
- PDFs, receipts, barcode labels, reports, exports, and document verification;
- API tokens, versioned API endpoints, health checks, backups, and recovery tools;
- standalone receipts, fixed assets, purchase returns, and operational documents;
- double-entry accounting, chart of accounts, journals, periods, ledger reports,
  historical cost snapshots, COGS, and depreciation posting;
- production SQL installer, production environment, documentation, built assets,
  Composer dependencies, and first-login credentials.

## Installation

Import `express-cloud-install.sql`, upload and extract the package, update the
database and hosting values inside `.env`, point the domain document root to
`public/`, and sign in using `FIRST_LOGIN.txt`.

Delete `FIRST_LOGIN.txt` from the server after first login and rotate the
administrator access key immediately.
